## Netflix Customer Retention & Growth Strategy

This capstone project uses Python and the CRISP-DM framework to analyze customer churn for a synthetic Netflix-like streaming service. It applies descriptive, diagnostic, predictive, and prescriptive analytics to identify churn risk and recommend retention, upgrade, and acquisition strategies.

### Repository Contents
Complete Jupyter Notebook with data preparation, analysis, and predictive modeling
PowerPoint presentation summarizing the findings and business recommendations

## Tools
Python, Pandas, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook, and PowerPoint
